# ühr

An alarm clock built on Josef Müller-Brockmann's grid: every hour is a square.

- **Prototype (v5):** https://naama2208-cloud.github.io/uhr/
- **Previous version (v4):** https://naama2208-cloud.github.io/uhr/v4.html
- **Design system:** https://naama2208-cloud.github.io/uhr/system.html

## v5 — one thing at a time
- **Home:** one week as a week — today and the six days after it, by name, no dates. Scroll on and it rolls round to today again. No logo, no clock, no "next" line. Now is the square with the orange frame.
- **Create:** tap (or pinch open) a square → five steps, one per screen: hour · minutes · name · sound · repeat. Only *delete* and *continue*.
- **Sound:** plays through the letters of the alarm's name.
- **Ring:** real — set one "in 1 minute" and it rings. Its square grows to the screen and the grid stays. A once-alarm disappears when it's done: no lists.
