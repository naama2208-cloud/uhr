# ühr

An alarm clock built on Josef Müller-Brockmann's grid: every hour is a square, and one gesture (pinch) moves between week, day and hour.

- **Prototype:** https://naama2208-cloud.github.io/uhr/
- **Design system:** https://naama2208-cloud.github.io/uhr/system.html
